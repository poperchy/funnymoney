# Стена с деньгами — контекст проекта

Веб-приложение для учёта личных финансов, где деньги показаны не цифрами, а как наличные купюры, разложенные по стене с ячейками-категориями.

## Идея

- Цифра в приложении «не ощущается», а пачка купюр, которая худеет на глазах, — ощущается («боль от оплаты» при наличных).
- Близкие аналоги: метод конвертов (Goodbudget, YNAB), тренд cash stuffing в TikTok. Но цифровой версии с «настоящими» купюрами на стене почти нет.
- Цель: публичный сайт, которым пользуются все желающие, а не личная игрушка.

## Продуктовые решения

- **Платформа:** сначала веб (десктоп, ~1440px), мобилка / Telegram Mini App — потом.
- **Валюта:** выбирается в настройках, номиналы подстраиваются.
- **Купюры:** стилизованные иллюстрированные, узнаваемые по цвету и номиналу (5, 10, 20, 50, 100, 200). Не фотореалистичные — из-за правил изображения банкнот и чтобы один стиль подходил под любую валюту.
- **Без регистрации в MVP:** данные в localStorage, человек зашёл и сразу пользуется. Аккаунты и синхронизация — если идея зайдёт.
- **Ввод вручную, без банков.** Сам жест «вытащил купюру» и есть фишка.
- **Минимум клавиатуры:** всё на кликах и перетаскивании, ввод цифрами — запасной вариант.
- **Тон:** юмор, на «ты», как друг с иронией. Добрый, без стыда за траты.

## Экраны и механики

### «Сколько получил?» (онбординг и каждая зарплата)
- Сверху из-за края высовывается иллюстрированная рука с пачкой наличных.
- Сумма набирается кликами по ряду купюр разных номиналов, пачка в руке толстеет. «−» / правый клик убирает. Ссылка «ввести вручную».
- Кнопка «Как в прошлый раз» подставляет прошлую зарплату.
- После подтверждения рука разжимается, купюры падают и рассыпаются в кучу внахлёст.

### Стена с деньгами (главный экран)
- Доска / пробковая стена, разбитая на ячейки-категории (Еда, Аренда, Транспорт, Развлечения, Подушка…). Размер ячейки зависит от бюджета.
- Купюры в ячейках лежат под разными углами, как положенные руками. Количество = остаток бюджета.
- Рядом куча «Нераспределено: N», купюры перетаскиваются из неё в ячейки. Кнопка «Разложить как в прошлый раз».
- Шапка: общий баланс, месяц, кнопка «Потратить». Справа — панель последних трат в виде бумажных чеков.

### Трата
- Купюру вытаскиваешь из ячейки и бросаешь в зону «Потрачено». Категория = ячейка, откуда взял.
- Если трата меньше купюры — ряд кнопок с номиналами сдачи, мелочь сама падает в копилку.
- Чипы с частыми суммами. Комментарий необязательный, скрыт.

### Копилка «Нужная мусорка»
- Копилка (свинка или банка) под стеной. Туда падает мелочь от сдачи, можно закинуть купюру перетаскиванием.
- Визуально наполняется.
- Забрать деньги: копилку надо «разбить» / потрясти + шуточное подтверждение.

### Перераспределение и пустые состояния
- Купюры перетаскиваются между ячейками, при наведении приподнимаются с тенью.
- Пустая ячейка — пунктирный контур.

### Примеры текстов
- После зарплаты: «Ого, богач! Ну давай раскладывать, пока не разлетелось»
- Маленькая зарплата: «Ну… бывает. Зато раскладывать быстро»
- Забрать из копилки: «Ты точно уверен, что хочешь забрать нажитое непосильным трудом?» → «Да, мне надо» / «Не, пусть лежит»
- Трата на развлечения: «Заслужил. Наверное»
- Пустая ячейка: «Тут было что-то. Было.»
- Нераспределённые купюры: «Деньги без дела грустят. Разложи их»
- Пустая копилка: «Свинка голодает»
- Почти пустая ячейка: «Осторожно, на донышке»
- Бросил в «Потрачено»: «Прощай, дружок»

## Модель данных

Купюры хранятся как объекты, а не как суммы по категориям (`src/model/types.ts`):

```ts
type Bill = {
  id: string;
  value: number;            // в минорных единицах (копейки), как и все суммы в приложении
  location: { type: 'cell'; cellId: string } | { type: 'pile' } | { type: 'piggy' };
  pose: { x: number; y: number; r: number }; // x/y — доля свободного места в ячейке 0..1, r — градусы
  z: number;
};
```

Потраченные купюры удаляются из массива, вместо них пишется `Receipt`. Монеты (`Wallet.coins`) лежат в кошельке (`location: 'wallet'` — мелочь с зарплаты), в ячейке (`'cell'` + `cellId`) или в копилке (сдача; в старых сохранениях `location` нет — значит копилка). `coinLocation`/`coinPlace` переводят это в термины `BillLocation`, а `totalIn`/`planSpend` считают купюры и монеты вместе. Свободные монеты перетаскиваются в ячейки, кошелёк и свинку (касса берёт только купюры). Разбитая свинка отдаёт всё: что разменивается — купюрами, остаток — монетами, всё в кошелёк.

«Куча» (`location: { type: 'pile' }`) на экране — большой кожаный кошелёк под доской (`purse` в `layout.ts`, рисуется в `paint.ts`). Купюры торчат из него вразнобой, две самые старые мелкие купюры лежат скомканными на кармане, монеты выглядывают из кармашка справа.

«Вытащить», «разменять», «бросить в копилку» — простые операции над массивом, Pixi только анимирует переходы.

## Стек

**Основа**
- Next.js + TypeScript (лендинг со SEO + приложение, деплой на Vercel)
- Effector — состояние
- effector-storage — сохранение в localStorage

**Сцена**
- PixiJS v8 — стена, купюры, копилка. Императивно, без @pixi/react: сцене нужен прямой доступ к спрайтам для GSAP, физики и drag. Рука в онбординге — SVG в DOM
- matter.js — физика падения и разлёта монет (если не хватит — Rapier)
- GSAP — точечные анимации в канвасе

**Интерфейс поверх канваса (гибрид)**
- Tailwind
- Radix UI — модалки, поповеры
- Motion (framer-motion) — анимации DOM-части

**Звук**
- Howler.js — шелест купюр, звон монет, хруст копилки

**Потом**
- Supabase — аккаунты и синхронизация
- PostHog — аналитика онбординга
- next-intl — английский

Архитектура: канвас Pixi рисует сцену, React-DOM поверх отвечает за шапку, панель чеков, модалки и тексты. Состояние в Effector, Pixi подписывается и отрисовывает.

## Разработка

```bash
npm run dev          # http://localhost:3000, приложение на /app, лендинг на /
npm run build
npm run lint
npm test             # vitest; один файл: npx vitest run src/model/ops.test.ts
npm run sounds       # пересобрать public/sounds/*.wav (синтезируются скриптом)
```

Сайт собирается в статику (`output: "export"`, папка `out/`) и публикуется на GitHub Pages workflow-ом `.github/workflows/pages.yml` при пуше в `main`. Там `NEXT_PUBLIC_BASE_PATH=/<repo>`, локально он пустой. Ссылки на файлы из `public/` строить через `BASE_PATH` из `src/lib/paths.ts`, а переходы между лендингом и `/app` — через `pageHref` (обычный `<a>`, без префетча Next). Проверить сборку локально: `NEXT_PUBLIC_BASE_PATH=/funnymoney npm run build` (в Git Bash добавить `MSYS_NO_PATHCONV=1`).

Next.js 16 — см. AGENTS.md: перед кодом под Next читать доки в `node_modules/next/dist/docs/`.

### Как устроен код

- `src/model/ops.ts` — чистые функции над `Wallet` (доход, перенос, трата со сдачей, авто-раскладка, разбивание копилки). Вся денежная логика тут, она покрыта тестами. Новые операции — сюда, с тестом.
- `src/model/wallet.ts` — Effector-стор `$wallet` (персистится целиком в `localStorage` под ключом `nalichka:wallet`) и события, которые вызывают `ops`.
- `src/model/ui.ts` — состояние интерфейса: экран, тема, drag, черновик траты (`$spendDraft`), ритуал копилки (`$pigFlow`), тосты.
- `src/scene/WallScene.ts` — Pixi-сцена. Ничего не меняет в деньгах: `apply(wallet)` сравнивает с предыдущим состоянием и анимирует разницу (новые купюры падают, перенесённые едут, потраченные улетают). Drag стартует в сцене, призрак купюры рисуется в DOM (`DragGhost`), чтобы пролетать над DOM-кассой «Потрачено».
- `src/scene/piggy.ts` — свинка и matter.js-физика монет в её локальных координатах.
- `src/scene/paint.ts` — Canvas2D-рисовалки купюр, монет и доски. Один рендер купюры идёт и в Pixi-текстуру, и в DOM (`billUrl`), чтобы купюры везде выглядели одинаково. Ждёт загрузки шрифта (`MoneyApp` гейтит рендер).
- `src/scene/layout.ts` — геометрия сцены в px дизайна (ширина 1060). Высота доски — ровно по рядам, которые заняли ячейки (минимум один). У категории хранится только размер (`colSpan`/`rowSpan`), позиции считает `packCells` — плотная упаковка по порядку на сетке в 8 колонок, как `grid-auto-flow: dense`. Дефолтные категории в этом порядке дают раскладку 8×4 из дизайна. Доска растёт и сжимается рядами, а полка с кучей и свинкой съезжает следом. Стор `$layout` пересчитывается только при изменении категорий. DOM-оверлей (`WallOverlay`: бумажки-ярлыки, подписи, подсветки, кнопка «+ Ячейка») использует ту же раскладку.
- Приложение свёрстано под 1440px и целиком масштабируется `transform: scale` на узких экранах (`MoneyApp`).
- Уже 720px (`MOBILE_QUERY` в `MoneyApp`) включается мобильная версия `src/components/mobile/` по `design/Funny Money Mobile.dc.html`. Без Pixi, стена на DOM: 4 колонки (`packCells(cats, 4)`), стена скроллится, внизу док «Потрачено» + свинка. Купюра перетаскивается долгим нажатием (`useDrag` в `MobileWall`), а без перетаскивания всё доступно тапом по ячейке (`CellSheet`). Шторки снизу (`Sheet`) открываются через `$sheet` в `src/model/mobile.ts`, трата — через тот же `$spendDraft`. Модель, `ops` и диалоги ячейки/чека/размена общие с десктопом. Скинов на мобилке пока нет.
- `/app` — одна высокая сцена из трёх остановок: рука → стол → стена (`$stop` в `ui.ts`). Пользователь между ними не скроллит: окно `MoneyApp` высотой с текущую остановку (`overflow: clip`, не `hidden` — иначе фокус прокручивает контейнер), а «камера» едет `translateY`. Рука и стол — по высоте вьюпорта, стена — своей высоты, внутри неё обычный скролл страницы. `Onboarding` перемонтируется на каждую новую зарплату (`key={$incomeRound}`).
- `src/lib/money/currency.ts` — валюты: номиналы купюр и монет, коэффициент для бюджетов по умолчанию (бюджеты в `defaults.ts` заданы в BYN). Смена валюты обнуляет кошелёк.
- `design/` — экспорт из Claude Design, только как референс; `Money Wall v3.dc.html` — актуальный прототип со всеми текстами и механиками. Исключён из линта и tsconfig.- Уведомления (`$toast`) — реплики свинки: `Toast` рисует облачко над её головой (позиция считается по канвасу и `layout.piggy`), а когда свинки не видно — в углу экрана с мордочкой. Сцена в этот момент вызывает `pigTalk()`.
- Карточка «добавить ячейку» — часть раскладки (`layout.addCell`): занимает первую свободную клетку 1×1, а если сетка заполнена — отдельный ряд во всю ширину.
- Скины доски и кошелька — `src/scene/skins.ts` (цвета и фактура на обе темы, цена). Выбранные и открытые хранятся в `src/model/skins.ts`. Донат пока тестовый: `ShopDialog` имитирует оплату и просто открывает скин. Настоящую оплату подключать там.
- Размен — `exchangeOptions`/`exchangeSplit`/`exchangeMerge` в `ops.ts`. Разбивает купюру на следующий номинал вниз (самую мелкую — на монеты) и собирает мелочь в крупную, только если сумма сходится точно. Окно размена открывается кнопкой «⇄ Размен» у кошелька или двойным/правым кликом по купюре или монете.
