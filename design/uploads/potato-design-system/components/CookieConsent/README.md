# CookieConsent

A 420px card bottom-left with `shadow-overlay`: “Cookies, briefly”, one honest sentence, and Accept (`dark`), Reject (`secondary`) and Settings (`link`). Settings reveals a switch per category (Essential locked on) and turns Accept into “Save choices”.

- `fixed` pins it to the viewport; without it the component renders inside a demo stage.
- Reject is as easy to reach as Accept; never pre-tick analytics.
