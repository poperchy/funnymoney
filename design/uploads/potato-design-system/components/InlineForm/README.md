# InlineForm

One-field pill form: an email input and a `dark` button inside a white pill with a `line` border. Used for the newsletter and “Notify me”.

- The button label flips to `doneLabel` (“Subscribed ✓”, “On the list ✓”) after submit; wire `onSubmit(value)` to your endpoint.
- `size="sm"` is the compact version for the coming-soon panel.
