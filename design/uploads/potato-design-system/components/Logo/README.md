# Logo

The potato mark — a 20px disc in the logo gradient (`violet-light` → `pink`, 135°) — beside the lowercase wordmark set in Instrument Sans 600 at 17px, −0.02em.

- Pass `section` to append a sub-label (`/ writing`, `/ blocks`) for sub-sites, 12px `ink-muted`.
- `size="sm"` is the footer form: a 16px disc and the name as 13px `ink-muted` text.
- The wordmark is always lowercase "potato". Never draw the mark in a flat colour or add a stroke.
- There is no image logo in the sources; the mark is CSS. Use this component rather than redrawing it.
