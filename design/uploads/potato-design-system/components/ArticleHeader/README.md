# ArticleHeader

The top of a post: breadcrumb, `h1` (52/1.06, −0.045em, balanced), `lead` in `ink-secondary`, then a byline row ruled off with `line` — avatar (38px, `grad-dot-1`, initial in white), name and role, and meta (date · read time) in `ink-muted`.

- Provide `title`, `lead`, `author {name, role, initial?}`, `date`, `datetime`, `readTime`, `breadcrumb`.
- Sits in the 720px `measure` column; the page provides the blobs behind it.
