# PostCard

A post in a grid: white `radius-card` card with a category Chip, an 18px title, a 14px dek in `ink-secondary`, and the date in 12px `ink-faint` pinned to the bottom. With `stat` it grows a tinted head (`grad-tile-N` by `index`) showing the post’s headline number — the blog index style.

- Provide `category`, `title`, `dek`, `date`, `readTime?`, `href` or `onClick`.
- Keep deks to one sentence; titles are sentence case.
