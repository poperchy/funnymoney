# Chip

Instrument Sans 500, 12px, sentence case, 3px × 10px pill. It names the category of a post, or a badge on a tier.

- Category tones are picked from the label: Benchmark → `accent`, Comparison → `cat-comparison`, By role → `cat-role`, Engineering → `success`; anything else is `neutral`.
- `tone="featured"` is the gradient “most picked” badge on a pricing tier.
- One chip per card, top-left. Do not use chips as buttons.
