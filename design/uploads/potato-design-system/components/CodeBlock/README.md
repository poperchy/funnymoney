# CodeBlock

Code on `surface-inverse` in the system monospace (`code` family — no web font, and nowhere outside code) at 13/1.75: a header with the file name and language in `code-comment`, or tabs when given several `files`. JSON-ish code is coloured automatically — keys `code-key`, strings `code-string`, numbers and booleans `code-number`, `//` comments `code-comment`; pass `plain` to skip it.

- `window` is the floating version of the code showcase: `radius-3xl` and `shadow-float`.
- Long lines scroll inside the block.
