# HeroCentered

`hero.centered` — the home-page opener. Two blurred blobs (`blob-violet` left, `blob-pink` right) float behind a `display-xl` headline (60/1.04) whose last words may take the signature gradient via `highlight`, an 18px lead (max 580px), and a primary + glass button pair.

- No eyebrow, pill or kicker above the headline — the headline opens the block.
- One gradient phrase, at the end of the headline. Lead: one sentence, two at most.
- Blobs stop animating under `prefers-reduced-motion`.
