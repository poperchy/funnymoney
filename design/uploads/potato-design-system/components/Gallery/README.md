# Gallery

`gallery.masonry` — a four-column dense grid of 150px rows; tiles may span `big` (2×2), `wide` or `tall`. Each tile opens a lightbox: the image on its tile gradient, the caption, and ←, →, ✕. Placeholder tiles show a small label until `src` is set.

- `inlineLightbox` keeps the lightbox inside the block (for spec pages).
