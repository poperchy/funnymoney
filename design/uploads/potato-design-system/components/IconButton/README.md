# IconButton

Round 40px button for arrows (sliders, lightbox) — `surface-raised` with a `line-control` border; `glass` makes it 38px on `surface-glass` for tinted grounds (testimonial spotlight).

- Always pass `label` (it becomes `aria-label`); the child is a glyph: ←, →, ✕.
- Disabled shows at 35% opacity (first/last slide).
